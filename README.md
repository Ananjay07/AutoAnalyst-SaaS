# AutoAnalyst — Client-Side Data Analytics Engine

AutoAnalyst is a lightweight, high-performance client-side spreadsheet parsing and data auditing dashboard. It provides automatic data-sanity profiling, predictive factor ranking, and plain-language executive summaries directly in browser memory without sending data to any external server.

## ✨ Features

- 🔒 **Zero Data Footprints**: Computations run 100% locally inside browser memory for complete security.
- 📊 **Data Sanity Profiling**: Automatic anomaly detection, missing value checks, and datatype validation.
- 🎯 **Predictive Driver Rankings**: Calculates correlation and impact factors for business metrics.
- 📝 **Executive Briefings**: Automatically generates plain-language summary reports for dataset insights.
- 🎨 **Modern Dark-Mode UI**: Features smooth canvas particle backgrounds, customizable themes, micro-animations, and fluid layout cards.

## 🛠️ Built With

- **HTML5**: Semantic layout and structured simulator components.
- **Vanilla CSS**: Custom design system, CSS variables, glassmorphism, responsive grid, and fluid animations.
- **JavaScript (ES6+)**: Custom canvas rendering engine, mathematical correlation formulas, and tab state management.

## 🚀 Quick Start

1. **Clone the repository**:
   ```bash
   git clone <YOUR_REPO_URL>
   cd <REPO_NAME>
   ```

2. **Run locally**:
   Open `index.html` in any web browser (or serve using VS Code Live Server / `python -m http.server`).
